# YLand 项目需求与发展路线

YLand 项目需求与发展路线

# 一、项目定位

YLand 是一个结合 AI
软件分发、游戏发行、公开经营账本、项目资产交易和区块链技术的平台。

传统 AI
软件和游戏平台通常依靠下载量、用户评分和排行榜体现产品价值，但这些数据大多由平台自己统计，外部很难真正验证。

YLand
希望通过统一支付系统和区块链账本，记录软件、游戏以及后续实体商业项目的真实经营数据，例如：

收入

下载量

在线人数

活跃用户

交易量

项目资产发行

分红记录

YLand 的核心目标是：

让软件、游戏和商业项目的真实经营表现可以被公开验证，并让消费者、开发者、项目方和投资者共同参与项目价值增长。

第二阶段同时在 Solana 网络发行 YDA，并与 YLand

第二阶段的 YDA发行在 Solana 网络上，并与 YLand 项目交易所同时上线。

对于普通用户来说，YDA的买入和卖出都由系统在后台自动处理。

### 3. YDA智能增发

系统会在后台持续收集与 YDA供应和平台需求有关的数据，例如：

用户支付需求

项目结算需求

当平台中可用于正常支付和结算的
YDA低于内部设定的安全水平时，系统会自动计算需要增加的 YDA数量，并在
Solana 上执行增发。

具体增发公式、阈值和内部参数不公开。

但是每次增发都会通过零知识证明进行验证。

零知识证明可以证明：

本次增发符合既定规则

增发数量由既定计算逻辑产生

系统没有临时改变规则

实际增发数量没有超过允许范围

用户和第三方可以验证增发结果符合规则，但无法看到完整的增发公式和内部参数。

基本流程为：

后台收集数据 \> → 判断 YDA是否不足 \> → 内部公式计算增发数量 \> →
生成零知识证明 \> → 验证证明 \> → 调用 Solana 合约自动增发 \> →
新币进入指定流动性或储备账户 \> → 公开增发记录和验证结果

### 6. 项目交易市场

YLand
建立独立于外部金融市场的内部商业项目交易市场。交易所不接入或引用股票、加密货币等外部行情，项目价格、成交量和价格走势均由
YLand 内部交易形成。

YLand 项目交易市场与传统证券交易所及传统虚拟货币交易所存在明显区别：

与传统证券交易所不同，YLand
不交易外部上市公司的股票，也不设置固定的开市、收市及统一每日结算时间。

与传统虚拟货币交易所不同，YLand 不以 BTC、ETH
等外部加密资产作为主要交易对象，也不接入或引用外部虚拟货币行情。

YLand
的主要交易对象是平台内商户、软件、游戏及其他商业项目发行的项目资产，每个商户或项目都可以对应一种独立的可交易项目资产。

所有项目资产统一以港币（HKD）报价和成交，其他货币需要先完成换汇，再以港币参与交易。

项目价格、成交量和价格走势只由 YLand
内部交易形成；市场连续运行，成交后即时更新港币余额、项目资产持仓和交易账本。

所有项目资产统一以港币（HKD）报价和交易。用户使用其他法定货币时，需要先完成换汇，再以港币参与项目资产交易。

每个商户或项目对应一种独立的可交易项目资产，其形式类似平台内独立的资产单位，可以代表股权、收益权、项目份额或其他约定权益。

用户购买后，项目资产可以进入 YLand 钱包，并在账户中查看、持有和交易。

YLand 项目交易市场连续运行，不设置传统证券市场的开市和收市时间。

交易完成后即时更新港币余额、项目资产持仓和交易账本，不设置统一的每日结算时间。

用户可以：

查看实时价格、历史成交和成交量

查看价格走势图和钱包持仓

## 第三阶段：建设 YLand 自有公链

YDA将从 Solana 迁移到 YLand 自有公链。

审计记录

### 2. YDA迁移

YDA采用锁定和映射的方式迁移。

平台统一完成整个迁移过程，用户不需要自己进行兑换，不需要手动转账，也不需要操作跨链桥。

迁移流程为：

平台确定迁移快照时间

记录所有用户 YDA余额

将 Solana 上的对应 YDA统一锁定

在 YLand 公链生成等量 YDA

按照一比一比例自动分配到用户账户

YLand 支付、交易和提现系统切换到自有公链

例如：

用户在迁移前拥有 1,000 枚 Solana 版本 YDA。

迁移完成后，系统自动将其转换成 1,000 枚 YLand 公链版本 YDA。

对于用户而言：

账户不变

余额不变

使用方式不变

不需要任何额外操作

### 3. 迁移保障

系统需要确保：

Solana 锁定数量和新链发行数量一致

不产生重复 YDA

用户余额不会减少

迁移记录可以验证

旧币锁定地址公开

新币发行记录公开

整个迁移过程可以审计

# 六、YLand 核心价值

YLand 最终希望解决的核心问题是：

### 1. 让项目价值更真实

传统平台主要依靠评分和下载量。

YLand 通过真实收入、用户数量、在线人数、交易量和分红数据体现项目价值。

### 2. 让经营数据更透明

项目经营数据进入公开账本和区块链记录。

用户可以看到一个项目实际赚了多少钱、发展得怎么样。
